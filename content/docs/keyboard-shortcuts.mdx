# Keyboard Shortcuts

Browsers reserve some Mac shortcuts (⌘W, ⌘Q, ⌘Tab, ⌘N, ⌘Space), so this Mac uses browser-safe alternatives.

| Action | Shortcut |
|---|---|
| Spotlight | `⌘K` / `Ctrl+K` or `/` |
| Close window | `⌥W` |
| Quit app | `⌥Q` |
| Minimize window | `⌥M` |
| Switch apps | `⌥Tab` |
| Quick Look | `Space` on a selected file |
| Open selection | `Enter` or `⌘↓` |
| Move selection | Arrow keys |
| Go to enclosing folder | `⌘↑` / `Backspace` |
| Close menus, Spotlight, Quick Look | `Esc` |
| Menu bar | `F10` focuses the menu bar, then arrow keys |
