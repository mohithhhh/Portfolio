# Provenance

**Ensemble AI-content detection suite** · Oct 2026 · [provenance.mohithog7.workers.dev](https://provenance.mohithog7.workers.dev/)

## What it does

- Built an **ensemble AI-content detector** (GPT-2 perplexity, conformally calibrated classifier, C2PA, watermarking) that surfaces **per-sentence attribution** and method disagreement instead of a single confidence score.

## Attack Lab

- Added an **Attack Lab** that stress-tests each detector with live structural and **T5 paraphrase attacks**, plus a semantic retrieval ledger (fastembed, SQLite).
- **FastAPI + Next.js** stack with batch mode and Docker deploy config.

**Stack:** GPT-2 · conformal prediction · C2PA · watermarking · T5 · fastembed · SQLite · FastAPI · Next.js · Docker
