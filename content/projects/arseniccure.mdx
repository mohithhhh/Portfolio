# ArsenicCure

**AI-powered arsenic skin lesion detection and severity grading** · Sep 2024 – present

## Model

- Developed a hybrid deep learning model integrating **ResNet-18, MobileNet-v2 and ViT** architectures using PyTorch.
- Achieved **88.33% test accuracy** and an **F1-score of 0.88** on a balanced dataset of **3,462 skin lesion images** classified into mild, moderate, normal and severe categories.

## Application

- Currently deploying a full-stack application for real-time severity grading and clinician validation.
- Builds on previously implemented explainable AI features (**Grad-CAM**) and a stack including **FastAPI, Docker and MongoDB**.

**Stack:** PyTorch · ResNet-18 · MobileNet-v2 · ViT · Grad-CAM · FastAPI · Docker · MongoDB
